# 🛒 הסל החכם – גרסת הענן

רשימת קניות משותפת, תכנון ארוחות, השוואת מחירים בין רשתות ומילוי עגלה באתר הסופר.
האפליקציה רצה באינטרנט 24/7, בלי מחשב דולק ובלי התקנה. נכנסים מהטלפון או מהמחשב עם חשבון Google.

| מה | איפה זה רץ | עלות |
|---|---|---|
| האתר עצמו | GitHub Pages | חינם |
| עדכון המחירים (כל שעה) | GitHub Actions | חינם |
| הרשימה המשותפת וההתחברות | Firebase (Google) | חינם |

---

## הקמה (פעם אחת, כ-20 דקות)

### שלב 1: GitHub – המקום של האתר
1. נכנסים ל-[github.com](https://github.com) ופותחים חשבון חינמי (אם אין).
2. למעלה מימין: **+** ← **New repository**.
   - Repository name: `superlist`
   - לבחור **Public** (חובה, כדי ש-GitHub Pages יהיה חינמי. הקוד והמחירים גלויים, אבל **הרשימה שלך לא**: היא נשמרת ב-Firebase ומוגנת).
   - **Create repository**.
3. בדף שנפתח: **uploading an existing file**. גוררים לחלון את **כל התוכן** של התיקייה `superlist-cloud` (כולל התיקייה `.github`) ← **Commit changes**.
   > אם התיקייה `.github` לא עלתה (היא "מוסתרת"): **Add file ← Create new file**, שם הקובץ `.github/workflows/site.yml`, ומדביקים את התוכן של הקובץ הזה מהמחשב.
4. **Settings** ← **Pages** ← תחת Source לבחור **GitHub Actions**.
5. כתובת האתר שלך תהיה: `https://<שם-המשתמש>.github.io/superlist/`

### שלב 2: Firebase – הרשימה המשותפת
1. נכנסים ל-[console.firebase.google.com](https://console.firebase.google.com) עם חשבון ה-Google שלך ← **Create a project** ← שם: `superlist` (Google Analytics: אפשר לכבות).
2. **Build ← Authentication ← Get started ← Google ← Enable** ← בוחרים מייל תמיכה ← **Save**.
3. ב-Authentication: **Settings ← Authorized domains ← Add domain** ← `<שם-המשתמש>.github.io`.
4. **Build ← Firestore Database ← Create database** ← מיקום `eur3 (europe-west)` ← **Start in production mode**.
5. ב-Firestore: לשונית **Rules** ← מוחקים הכל, מדביקים את התוכן של הקובץ `firestore.rules` ← **Publish**.
6. ⚙️ (Project settings) ← למטה **Your apps** ← הסמל `</>` (Web) ← שם: `superlist` ← **Register app**. מופיע קוד עם `firebaseConfig = { apiKey: ... }`.
7. מעתיקים את ששת הערכים לקובץ `docs/firebase-config.js` (ב-GitHub: פותחים את הקובץ ← ✏️ עריכה ← מדביקים ← **Commit changes**).
   > הערכים האלה לא סיסמה. הם מזהים את הפרויקט, והנתונים מוגנים בכללים משלב 5.

### שלב 3: מתחילים
1. בלשונית **Actions** ב-GitHub רואים ריצה ירוקה ✓ (2-3 דקות). אם לא רצה: **Actions ← "האתר והמחירים" ← Run workflow**.
2. נכנסים לכתובת האתר ← **התחברות עם Google**. מי שמתחבר ראשון הוא בעל הרשימה.
3. **⚙️ הגדרות** ← בוחרים סניף בכל רשת. המחירים יופיעו תוך שעה בערך, בעדכון האוטומטי הבא.
4. **👥 שיתוף הרשימה** ← מוסיפים את ה-Gmail של בן/בת הזוג ← שולחים להם את הקישור.
5. בטלפון: פותחים את האתר ← תפריט הדפדפן ← **הוספה למסך הבית**.

## 🛒 מילוי עגלה באתר הסופר

האפליקציה לא נכנסת לחשבון שלך באתר הסופר. במקום זה יש **כפתור סימנייה** שאתה לוחץ עליו בדפדפן שלך, כשאתה כבר מחובר לאתר:

1. **פעם אחת:** ⚙️ הגדרות ← "איך מוסיפים את כפתור המילוי". במחשב גוררים את הכפתור לסרגל הסימניות.
2. ברשימה: **🛒 שלח לסופר** ← בוחרים רשת. האתר שלה נפתח בלשונית חדשה.
3. באתר הסופר (מחובר לחשבון) לוחצים על הסימנייה **🛒 מלא עגלה**. הפריטים נוספים לעגלה, ירקות ופירות לפי ק"ג ושאר המוצרים לפי כמות, ובסוף עוברים לעגלה.
4. **בודקים ומשלמים בעצמכם.** הכפתור לא מבצע תשלום.

נתמך: שופרסל, רמי לוי, יוחננוף, טיב טעם, ויקטורי.

## חשוב לדעת
- המחירים באים מקבצי **שקיפות המחירים** שהרשתות מפרסמות לפי חוק, ומתעדכנים כל שעה. ייתכנו הבדלים קטנים מהאתר (מבצעי מועדון, דמי משלוח).
- ויקטורי לא מפרסמת כרגע קבצי מחירים, לכן היא בלי השוואה, אבל אפשר למלא בה עגלה.
- הרשימה נשמרת גם בטלפון, כך שאפשר לערוך אותה בלי קליטה. היא מסתנכרנת כשהחיבור חוזר.
- רק מיילים שברשימת השיתוף יכולים לראות ולערוך את הרשימה.
